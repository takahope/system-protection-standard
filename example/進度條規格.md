# 送出後 Excel 產生進度條規格

## 1. 適用範圍

本文件描述「綜合確認」頁面中，使用者按下「確認送出並下載 Excel」後出現的送出進度條。

此進度條只用於送出批次差勤申請時的等待狀態，涵蓋：

- 送出補請假、補加班、忘刷卡混合申請。
- 呼叫後端產生 Excel。
- 寫入差勤紀錄。
- 寄送通知與附件。
- 前端下載 Excel 前的完成提示。

此進度條不是主流程步驟列；主流程步驟列使用另一組 `.progress-panel`、`.progress-track`、`.progress-bar`。

## 2. 顯示時機

進度條面板在進入「綜合確認」頁面時就會被建立，但預設隱藏。

建立位置：

- 前端函式：`renderBatchReview()`
- 建立函式：`createSubmitProgressPanel()`
- DOM id：`submit-progress-panel`

預設狀態：

- `.submit-progress-panel` 為 `display: none`
- 百分比顯示 `0%`
- 摘要文字顯示 `等待送出`
- 進度條寬度為 `0%`

使用者按下「確認送出並下載 Excel」後，`submitBatch()` 會呼叫 `startSubmitProgress()`，並將面板加上 `.is-active`。

啟用後：

- `.submit-progress-panel.is-active` 改為 `display: block`
- 播放 `stage-in 260ms cubic-bezier(.2, .8, .2, 1)` 動畫
- 開始每 120ms 更新一次百分比

## 3. DOM 結構

目前進度條由 `createSubmitProgressPanel()` 動態產生，結構如下：

```html
<section class="submit-progress-panel" id="submit-progress-panel" aria-live="polite">
  <div class="submit-progress-meta">
    <span id="submit-progress-title">正在準備 Excel</span>
    <span id="submit-progress-percent">0%</span>
  </div>

  <div class="submit-progress-track" aria-hidden="true">
    <div class="submit-progress-bar" id="submit-progress-bar"></div>
  </div>

  <p class="submit-progress-summary" id="submit-progress-summary">等待送出</p>
</section>
```

DOM 欄位用途：

| id | 用途 |
|---|---|
| `submit-progress-panel` | 進度條外層面板，控制顯示或隱藏 |
| `submit-progress-title` | 顯示目前標題 |
| `submit-progress-percent` | 顯示目前百分比 |
| `submit-progress-bar` | 以 `width` 呈現進度 |
| `submit-progress-summary` | 顯示目前處理階段文案 |

## 4. 按鈕與送出狀態

按下送出後，`submitBatch()` 會立即進入送出狀態。

送出中：

- `submit-button` 停用。
- `add-item-button` 停用。
- `clear-list-button` 停用。
- 送出按鈕文字改為 `產生 Excel 中...`。
- 清除既有訊息。
- 啟動進度條。

送出成功：

- 進度條補到 `100%`。
- 若後端回傳 `base64`，前端下載 Excel。
- 顯示列印提醒彈窗。
- 顯示成功訊息。
- `batchSubmitted` 設為 `true`。
- 送出按鈕文字改為 `已送出`，並維持停用。
- `add-item-button` 與 `clear-list-button` 重新啟用。

送出失敗：

- 呼叫 `resetSubmitProgress()`。
- 送出按鈕恢復可點。
- `add-item-button` 與 `clear-list-button` 恢復可點。
- 送出按鈕文字恢復為 `確認送出並下載 Excel`。
- 顯示錯誤訊息。

## 5. 百分比推進規則

進度條啟動時會記錄開始時間：

```javascript
submitProgressStartedAt = Date.now();
submitProgressValue = 0;
```

接著每 120ms 執行一次：

```javascript
const elapsed = Date.now() - submitProgressStartedAt;
const percent = Math.min(90, Math.floor((elapsed / 10000) * 90));
if (percent > submitProgressValue) setSubmitProgress(percent);
```

推進規則：

- 進度從 `0%` 開始。
- 以前端計時模擬進度。
- 約 10 秒推進到 `90%`。
- 在後端尚未完成前，最高只會停在 `90%`。
- 後端成功回傳後，才會由 `finishSubmitProgress()` 設為 `100%`。
- 若新計算出的百分比沒有高於目前值，不會重複更新。

此設計避免後端仍在處理時，前端進度條提前顯示完成。

## 6. 完成與重置規則

### 6.1 完成

成功送出後會呼叫 `finishSubmitProgress()`：

```javascript
clearSubmitProgressTimer();
setSubmitProgress(100, 'Excel 已準備完成，開始下載');
return new Promise(resolve => window.setTimeout(resolve, 260));
```

完成行為：

- 停止 interval。
- 進度設為 `100%`。
- 摘要文字強制顯示 `Excel 已準備完成，開始下載`。
- 等待 260ms，讓進度條完成動畫有時間呈現。
- 之後才執行下載、成功訊息與送出完成狀態。

### 6.2 重置

以下情境會呼叫 `resetSubmitProgress()`：

- 進入綜合確認頁。
- 清空目前申請列表。
- 送出失敗。

重置行為：

- 停止 interval。
- `submitProgressStartedAt` 設為 `0`。
- `submitProgressValue` 設為 `0`。
- 移除面板的 `.is-active`。
- 進度設為 `0%`。
- 摘要文字顯示 `等待送出`。

## 7. 文字規則

標題文字由 `setSubmitProgress()` 控制：

| 條件 | 標題 |
|---|---|
| 百分比小於 100 | `正在準備 Excel` |
| 百分比大於等於 100 | `Excel 準備完成` |

摘要文字預設由 `getSubmitProgressSummary(percent)` 依百分比產生。

| 百分比條件 | 摘要文字 |
|---|---|
| `0%` 到 `19%` | `正在整理申請內容` |
| `20%` 到 `39%` | `正在寫入差勤紀錄` |
| `40%` 到 `59%` | `正在建立 Excel 申請表` |
| `60%` 到 `79%` | `正在套用表單格式` |
| `80%` 到 `99%` | `正在寄送通知與附件` |
| `100%` | `Excel 已準備完成，開始下載` |

若 `setSubmitProgress(percent, forcedSummary)` 傳入 `forcedSummary`，摘要文字會優先使用指定文字。

目前只有完成時會強制指定：

```text
Excel 已準備完成，開始下載
```

## 8. 視覺樣式

外層面板 `.submit-progress-panel`：

- 預設 `display: none`
- 上方間距：`16px`
- 內距：`18px`
- 邊框：`1px solid rgba(15, 123, 104, 0.14)`
- 圓角：`20px`
- 背景：`rgba(255, 255, 255, 0.82)`
- 陰影：`0 12px 34px rgba(23, 33, 29, 0.08)`

啟用狀態 `.submit-progress-panel.is-active`：

- `display: block`
- 動畫：`stage-in 260ms cubic-bezier(.2, .8, .2, 1)`

標題列 `.submit-progress-meta`：

- 使用 flex 水平排列。
- 左側為狀態標題，右側為百分比。
- 兩側間距：`gap: 12px`
- 底部間距：`12px`
- 文字顏色：`var(--accent-dark)`
- 字級：`14px`
- 字重：`900`

軌道 `.submit-progress-track`：

- 高度：`12px`
- 圓角：`999px`
- 背景：`#e7eee9`
- 超出隱藏：`overflow: hidden`

進度條 `.submit-progress-bar`：

- 初始寬度：`0`
- 高度：`100%`
- 圓角繼承軌道。
- 背景：`linear-gradient(90deg, var(--accent), #72d7c2, var(--gold))`
- 寬度動畫：`transition: width 220ms ease`

摘要 `.submit-progress-summary`：

- 使用 flex 排列。
- 與圖示點間距：`9px`
- 上方間距：`12px`
- 文字顏色：`var(--muted)`
- 字級：`14px`
- 行高：`1.6`

摘要前方提示點 `.submit-progress-summary::before`：

- 尺寸：`9px × 9px`
- 圓角：`999px`
- 背景：`var(--gold)`
- 外光暈：`0 0 0 5px rgba(217, 154, 50, 0.14)`

## 9. 無障礙規格

外層面板設定：

```html
aria-live="polite"
```

用途：

- 讓輔助工具能以非打斷方式讀出進度狀態更新。
- 避免送出後狀態變化完全只靠視覺提示。

進度軌道設定：

```html
aria-hidden="true"
```

用途：

- 軌道本身只是視覺裝飾。
- 實際文字狀態由標題、百分比與摘要提供。

## 10. 目前限制

- 百分比是前端計時模擬，不代表後端真實子任務進度。
- `20%`、`40%`、`60%`、`80%` 的摘要文字是體感階段，不是後端事件回報。
- 若後端在 10 秒後仍未完成，進度會停在 `90%`。
- 若後端很快完成，進度會直接補到 `100%`，並至少保留 260ms 完成動畫。
- 失敗時不保留進度條錯誤狀態，而是重置為隱藏並顯示一般錯誤訊息。

## 11. 關聯函式摘要

| 函式 | 職責 |
|---|---|
| `renderBatchReview()` | 建立綜合確認頁與進度條面板 |
| `createSubmitProgressPanel()` | 產生進度條 DOM |
| `submitBatch()` | 控制送出流程、按鈕狀態、成功失敗處理 |
| `startSubmitProgress()` | 啟動進度條與 interval |
| `finishSubmitProgress()` | 成功時補到 100%，並等待完成動畫 |
| `resetSubmitProgress()` | 重置並隱藏進度條 |
| `clearSubmitProgressTimer()` | 停止 interval |
| `setSubmitProgress()` | 寫入百分比、標題、摘要與 bar 寬度 |
| `getSubmitProgressSummary()` | 依百分比回傳摘要文案 |
| `runSubmit()` | 呼叫 GAS 後端或本機 mock 送出 |
