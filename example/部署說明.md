# 資通系統防護基準管理系統 - 部署說明

## 一、新版自評表 (xlsx)

檔案：`資通系統防護基準自評表_新版.xlsx`

已依據最新「附表十 資通系統防護基準」建立 80 項控制措施，涵蓋 7 大構面。每個系統各一張工作表，符合性欄位已設定下拉選單（符合/部分符合/未符合/不適用），需填寫的項目以黃色底色標示，不適用項目以灰色底色標示。

## 二、Google Apps Script 網頁應用程式部署步驟

### 步驟 1：建立 Google Sheets
1. 前往 Google Sheets 建立新的試算表
2. 將試算表命名為「資通系統防護基準管理系統」

### 步驟 2：開啟 Apps Script
1. 點選上方選單「擴充功能」>「Apps Script」
2. 這會開啟 Apps Script 編輯器

### 步驟 3：貼入程式碼
1. 將 `AppScript_Code.js` 的內容貼入預設的 `Code.gs` 檔案中
2. 點選左側「+」按鈕 > 新增「指令碼」檔案，命名為 `env`，並將 `env.js` 的內容貼入
3. 點選左側「+」按鈕 > 新增「HTML」檔案，命名為 `Index`
4. 將 `AppScript_Index.html` 的內容貼入 `Index.html` 中

### 步驟 4：部署
1. 點選右上角「部署」>「新增部署作業」
2. 類型選擇「網頁應用程式」
3. 說明填入「資通系統防護基準管理系統」
4. 執行身分選擇「我」
5. 存取權限選擇「機構內的任何人」或「只有我」
6. 點選「部署」

### 步驟 5：初始化
1. 開啟部署後的網頁連結
2. 點選上方「系統初始化」按鈕
3. 先點「初始化試算表結構」建立工作表
4. 再點「匯入預設系統資料」匯入 11 個系統

## 三、功能說明

### 系統總覽
- 顯示所有系統的卡片式清單，含防護等級、系統屬性等摘要資訊
- 支援依系統名稱搜尋
- 頂部統計列顯示各等級系統數量
- 可直接新增系統（含附件4所有欄位）

### 全域儀表板
- 跨系統符合率比較表（應評數、符合數、完成率、進度條）
- 構面弱項熱區分析（各系統 × 各構面的符合/未符合矩陣）
- 不符合防護基準項目代碼彙總（一覽所有系統的 C 代碼）

### 系統管理 (CRUD)
- 新增系統：填寫附件4所有欄位
- 編輯系統：修改任何欄位
- 刪除系統：連同評估與自評資料一併清除

### 防護需求分級評估（附表九）
- 點入任一系統後，可對機密性、完整性、可用性、法律遵循性四構面分別評估
- 系統自動取四構面最高者為最終防護需求等級
- 評估結果會同步更新系統清冊的防護等級欄位

### 防護基準自評（附表十）
- 點選「防護基準自評」分頁
- 先點「初始化自評項目」產生該系統的 80 項控制措施
- 依系統等級自動標示應評與不適用項目
- 可逐項填寫符合性、現況說明、佐證資料、矯正作為
- 即時顯示完成率與統計
- 篩選功能：依構面、狀態篩選，可只看應評/未符合項目
- 批次儲存：一次儲存所有變更（不再逐筆呼叫）
- 自動計算不符合代碼：儲存後自動產生 C0101~C0703 代碼並寫回系統清冊

### 匯出報告
- 點選「匯出報告」按鈕，將自評結果匯出至 Google Sheets 新工作表
- 格式與自評表 xlsx 一致，含標題、系統資訊、色彩標記、不符合代碼摘要

## 四、資料結構

Google Sheets 會自動建立以下工作表：

| 工作表 | 用途 |
|---|---|
| 系統清冊 | 所有系統的基本資料（對應附件4欄位） |
| 防護需求分級評估 | 各系統的四構面分級評估紀錄 |
| 防護基準自評 | 各系統的 80 項控制措施自評紀錄 |
| 控制措施基準 | 附表十的 80 項控制措施參考表 |
